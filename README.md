# 🧾 Sistema de Gerenciamento de Estoque

Este é um sistema de gerenciamento de estoque com funcionalidade de vendas, desenvolvido puramente em **Java**, utilizando **interface gráfica (GUI)** sem frameworks externos. O sistema permite cadastrar, atualizar, remover e vender produtos, controlando os níveis de estoque em tempo real.

## 💻 Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE recomendada:** Eclipse, IntelliJ IDEA ou NetBeans
- **Interface Gráfica:** Java Swing (AWT/Swing puro)
- **Banco de Dados:** MySQL Server

## 🎯 Funcionalidades

### 🗃️ Gerenciamento de Produtos
- Cadastro de novos produtos (nome, código, descrição, preço, quantidade em estoque)
- Edição de produtos existentes
- Remoção de produtos
- Consulta de produtos por nome ou código

### 💰 Venda de Produtos
- Seleção de produto para venda
- Validação de quantidade disponível
- Atualização automática do estoque após venda
- Cálculo de valor total da venda

### 📈 Relatórios e Estatísticas
- Relatório de produtos em estoque
- Produtos com estoque mínimo atingido
- Histórico de vendas (se implementado)

### 🧩 Interface Gráfica
- Interface intuitiva utilizando Java Swing
- Menus e botões para fácil navegação
- Caixas de diálogo para feedback ao usuário

## 📌 Observações
- Projeto desenvolvido como parte de disciplina acadêmica.
- Nenhum framework externo foi utilizado.
